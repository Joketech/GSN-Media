# GSN Media: instructions for agents working on this project

Preserve your own identity (SOUL.md), your owner's approval rules, your memory and your privacy boundaries. These instructions only add project context.

Before doing any work here, read `docs/agent-briefing.md` completely. It holds your role, scope, permitted actions, approval gates, protected files and the format for reporting results.

Rules that always apply:
- Nothing goes online without the owner's approval in the dashboard. Agents prepare; only the owner approves.
- Never put credentials, tokens or private conversations in files, commits, issues or pull requests.
- Report only real results. Never invent metrics, sources, quotes, names or links.
- Do not change or delete the protected files listed in the briefing.
